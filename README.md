# Калькулятор зарплаты Дом.ру — Android

Проект для сборки устанавливаемого APK. Приложение открывает встроенный HTML-калькулятор и работает без интернета.

## Сборка без Android Studio (GitHub)
1. Создайте **пустой публичный или приватный** репозиторий на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория, сохранив скрытую папку `.github`.
3. Откройте **Actions → Build Android APK → Run workflow**.
4. После завершения откройте запуск и скачайте архив **domru-salary-apk** из раздела Artifacts.
5. Распакуйте архив, перенесите `app-debug.apk` на телефон и установите.

Для локальной сборки: Android Studio → Open (корень проекта) → Build APK(s).

Это debug APK для личной установки, не подписанный релизным ключом. Для Google Play понадобится релизная сборка и подпись.
